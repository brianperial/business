核心交易策略

收益：波动率溢价 + 时间价值
个人：长期持有，不止损不追高机构：定投 · 被动投资→ 可被系统性收租的空间
规则：量化对冲，不做高频
规则驱动做多 / 做空波动率靠策略设计，不靠速度
风险：先于收益
现金担保不做高频100 万以下可做末日期权量化风控体系
策略：不做个股期权，不赌涨跌
管理费 + 早期收益 = 风险缓冲指数 / ETF：流动性好 · 波动温和
组合优先于单笔交易
单笔交易 = 一个风险单元总敞口相关性流动性期限波动率尾部风险
概率优先于预测
不预测市场风险溢价长期统计优势
像保险公司一样，产品不预测方向，靠规则与风控，长期收取风险溢价。
